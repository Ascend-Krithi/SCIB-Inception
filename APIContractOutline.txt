API Contract Outline

1. Dashboard API
- Endpoint: GET /api/youth-accounts/{youthAccountId}/dashboard
- Request: Path param: youthAccountId
- Response:
  {
    "youthAccountId": "string",
    "accountBalance": "decimal",
    "spendingLimit": "decimal",
    "currency": "string",
    "recentTransactions": [
      {
        "transactionId": "string",
        "date": "datetime",
        "description": "string",
        "amount": "decimal"
      }
    ]
  }
- Error Handling: 403 Unauthorized, 404 Not Found, 500 Internal Error

2. Fund Transfer API
- Endpoint: POST /api/youth-accounts/{youthAccountId}/fund-transfer
- Request Body:
  {
    "sourceAccountId": "string",
    "transferAmount": "decimal",
    "currency": "string"
  }
- Response:
  {
    "transferId": "string",
    "status": "SUCCESS",
    "updatedBalance": "decimal"
  }
- Error Handling: 400 Insufficient Balance, 400 Invalid Account, 500 Transfer Service Failure

3. Spending Limit API
- Endpoint: PUT /api/youth-accounts/{youthAccountId}/spending-limit
- Request Body:
  {
    "weeklyLimit": "decimal"
  }
- Response:
  {
    "youthAccountId": "string",
    "weeklyLimit": "decimal",
    "status": "UPDATED"
  }
- Error Handling: 400 Validation Error, 403 Unauthorized

4. Transaction History API
- Endpoint: GET /api/youth-accounts/{youthAccountId}/transactions
- Query Parameters: startDate, endDate, page, pageSize
- Response:
  {
    "transactions": [
      {
        "transactionId": "string",
        "date": "datetime",
        "merchant": "string",
        "amount": "decimal",
        "transactionType": "debit | credit"
      }
    ],
    "pagination": {
      "page": "number",
      "pageSize": "number",
      "totalRecords": "number"
    }
  }
- Error Handling: 403 Unauthorized, 400 Invalid Params, 500 Internal Error

Authentication:
- OAuth 2.0 token required for all APIs
- RBAC enforced for parent/youth roles

Compliance:
- Input validation, output filtering, audit logging, RBAC applied to all endpoints
