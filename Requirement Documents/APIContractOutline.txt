API Contract Outline

--- Dashboard API ---
Endpoint: GET /api/youth-accounts/{youthAccountId}/dashboard
Request: Path param youthAccountId
Response:
{
  "youthAccountId": "string",
  "accountBalance": "decimal",
  "spendingLimit": "decimal",
  "currency": "string",
  "recentTransactions": [
    {
      "transactionId": "string",
      "date": "datetime",
      "description": "string",
      "amount": "decimal"
    }
  ]
}
Error Handling:
- 403 Unauthorized (invalid parent ownership)
- 404 Not Found (invalid youth account)
- 500 Internal Server Error

--- Fund Transfer API ---
Endpoint: POST /api/youth-accounts/{youthAccountId}/fund-transfer
Request Body:
{
  "sourceAccountId": "string",
  "transferAmount": "decimal",
  "currency": "string"
}
Response:
{
  "transferId": "string",
  "status": "SUCCESS",
  "updatedBalance": "decimal"
}
Error Handling:
- 400 Insufficient balance
- 400 Invalid account mapping
- 500 Transfer service failure

--- Spending Limit API ---
Endpoint: PUT /api/youth-accounts/{youthAccountId}/spending-limit
Request Body:
{
  "weeklyLimit": "decimal"
}
Response:
{
  "youthAccountId": "string",
  "weeklyLimit": "decimal",
  "status": "UPDATED"
}
Error Handling:
- 400 Invalid value
- 403 Unauthorized
- 500 Internal Server Error

--- Transaction History API ---
Endpoint: GET /api/youth-accounts/{youthAccountId}/transactions
Query Params: startDate, endDate, page, pageSize
Response:
{
  "transactions": [
    {
      "transactionId": "string",
      "date": "datetime",
      "merchant": "string",
      "amount": "decimal",
      "transactionType": "debit | credit"
    }
  ],
  "pagination": {
    "page": "number",
    "pageSize": "number",
    "totalRecords": "number"
  }
}
Error Handling:
- 403 Unauthorized
- 404 Not Found
- 500 Internal Server Error

--- Common ---
Authentication: OAuth2 Bearer Token
Authorization: RBAC (parent must own youth account)
Input Validation: All request parameters and bodies validated
Output Filtering: Only authorized parent data returned
Audit Logging: All API calls logged

--- OpenAPI/Swagger ---
Defined per SCIB-30 for all endpoints, request/response schemas, authentication, error structures, example payloads.
