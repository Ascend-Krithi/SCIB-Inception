# API Contract Outline: Youth Account Management

## 1. GET /api/youth-accounts/{youthAccountId}/dashboard
- **Method**: GET
- **Request**: Path param: youthAccountId
- **Response**:
```json
{
  "youthAccountId": "string",
  "accountBalance": "decimal",
  "spendingLimit": "decimal",
  "currency": "string",
  "recentTransactions": [
    {
      "transactionId": "string",
      "date": "datetime",
      "description": "string",
      "amount": "decimal"
    }
  ]
}
```
- **Error Handling**:
  - 403 Forbidden (unauthorized)
  - 404 Not Found (invalid account)

## 2. POST /api/youth-accounts/{youthAccountId}/fund-transfer
- **Method**: POST
- **Request**:
```json
{
  "sourceAccountId": "string",
  "transferAmount": "decimal",
  "currency": "string"
}
```
- **Response**:
```json
{
  "transferId": "string",
  "status": "SUCCESS",
  "updatedBalance": "decimal"
}
```
- **Error Handling**:
  - 400 Bad Request (insufficient funds, invalid mapping)
  - 500 Internal Server Error (transfer service failure)

## 3. PUT /api/youth-accounts/{youthAccountId}/spending-limit
- **Method**: PUT
- **Request**:
```json
{
  "weeklyLimit": "decimal"
}
```
- **Response**:
```json
{
  "youthAccountId": "string",
  "weeklyLimit": "decimal",
  "status": "UPDATED"
}
```
- **Error Handling**:
  - 400 Bad Request (invalid value)
  - 403 Forbidden (unauthorized)

## 4. GET /api/youth-accounts/{youthAccountId}/transactions
- **Method**: GET
- **Request Query Params**: startDate, endDate, page, pageSize
- **Response**:
```json
{
  "transactions": [
    {
      "transactionId": "string",
      "date": "datetime",
      "merchant": "string",
      "amount": "decimal",
      "transactionType": "debit | credit"
    }
  ],
  "pagination": {
    "page": "number",
    "pageSize": "number",
    "totalRecords": "number"
  }
}
```
- **Error Handling**:
  - 403 Forbidden (unauthorized)
  - 404 Not Found (invalid account)

## 5. Common Aspects
- **Authentication**: OAuth2 Bearer Token
- **Authorization**: RBAC, parent must own youth account
- **Validation**: All inputs validated, descriptive errors
- **Audit Logging**: All requests and changes logged
