API Contract Outline

Endpoint: GET /api/youth-accounts/{youthAccountId}/dashboard
- Method: GET
- Request Params: youthAccountId (path)
- Response:
  {
    "youthAccountId": "string",
    "accountBalance": "decimal",
    "spendingLimit": "decimal",
    "currency": "string",
    "recentTransactions": [
      {
        "transactionId": "string",
        "date": "datetime",
        "description": "string",
        "amount": "decimal"
      }
    ]
  }
- Error Handling: 403 Unauthorized, 404 Not Found, 500 Internal Server Error

Endpoint: POST /api/youth-accounts/{youthAccountId}/fund-transfer
- Method: POST
- Request Body:
  {
    "sourceAccountId": "string",
    "transferAmount": "decimal",
    "currency": "string"
  }
- Response:
  {
    "transferId": "string",
    "status": "SUCCESS|FAILED",
    "updatedBalance": "decimal"
  }
- Error Handling: 400 Bad Request (validation/insufficient funds), 403 Unauthorized, 500 Internal Server Error

Endpoint: PUT /api/youth-accounts/{youthAccountId}/spending-limit
- Method: PUT
- Request Body:
  {
    "weeklyLimit": "decimal"
  }
- Response:
  {
    "youthAccountId": "string",
    "weeklyLimit": "decimal",
    "status": "UPDATED"
  }
- Error Handling: 400 Bad Request (validation), 403 Unauthorized, 500 Internal Server Error

Endpoint: GET /api/youth-accounts/{youthAccountId}/transactions
- Method: GET
- Query Params: startDate, endDate, page, pageSize
- Response:
  {
    "transactions": [
      {
        "transactionId": "string",
        "date": "datetime",
        "merchant": "string",
        "amount": "decimal",
        "transactionType": "debit|credit"
      }
    ],
    "pagination": {
      "page": "number",
      "pageSize": "number",
      "totalRecords": "number"
    }
  }
- Error Handling: 403 Unauthorized, 404 Not Found, 500 Internal Server Error

Error Responses (All APIs):
- 400: { "error": "Validation error details" }
- 403: { "error": "Unauthorized" }
- 404: { "error": "Resource not found" }
- 409: { "error": "Conflict (e.g., duplicate transaction)" }
- 500: { "error": "Internal server error" }

RBAC:
- Only parent/guardian with valid session can access/manage youth account APIs
- Youth may access own account data (read-only)
- Admins can audit but not initiate transfers
