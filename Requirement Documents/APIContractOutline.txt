API Contract Outline

1. Endpoint: GET /api/youth-accounts/{youthAccountId}/dashboard
- Request: OAuth token in header
- Response:
{
  "youthAccountId": "string",
  "accountBalance": "decimal",
  "spendingLimit": "decimal",
  "currency": "string",
  "recentTransactions": [
    {
      "transactionId": "string",
      "date": "datetime",
      "description": "string",
      "amount": "decimal"
    }
  ]
}
- Error Handling: 403 Unauthorized, 404 Not Found

2. Endpoint: POST /api/youth-accounts/{youthAccountId}/fund-transfer
- Request Body:
{
  "sourceAccountId": "string",
  "transferAmount": "decimal",
  "currency": "string"
}
- Response:
{
  "transferId": "string",
  "status": "SUCCESS",
  "updatedBalance": "decimal"
}
- Error Handling: 400 Insufficient funds, 400 Invalid account, 500 Service failure

3. Endpoint: PUT /api/youth-accounts/{youthAccountId}/spending-limit
- Request Body:
{
  "weeklyLimit": "decimal"
}
- Response:
{
  "youthAccountId": "string",
  "weeklyLimit": "decimal",
  "status": "UPDATED"
}
- Error Handling: 400 Invalid value, 403 Unauthorized

4. Endpoint: GET /api/youth-accounts/{youthAccountId}/transactions
- Query Parameters: startDate, endDate, page, pageSize
- Response:
{
  "transactions": [
    {
      "transactionId": "string",
      "date": "datetime",
      "merchant": "string",
      "amount": "decimal",
      "transactionType": "debit | credit"
    }
  ],
  "pagination": {
    "page": "number",
    "pageSize": "number",
    "totalRecords": "number"
  }
}
- Error Handling: 403 Unauthorized, 400 Invalid params

5. Security & Compliance
- OAuth token required for all endpoints
- RBAC enforced: parent must own youth account
- Audit logging for all requests
- Input validation and output filtering
- OpenAPI/Swagger spec maintained
