# API Contract Outline: Youth Account Management

## 1. Retrieve Youth Account Dashboard
- **Endpoint:** GET /api/youth-accounts/{youthAccountId}/dashboard
- **Auth:** OAuth2 token (parent)
- **Request:** Path: youthAccountId
- **Response:**
  ```json
  {
    "youthAccountId": "string",
    "accountBalance": "decimal",
    "spendingLimit": "decimal",
    "currency": "string",
    "recentTransactions": [
      {
        "transactionId": "string",
        "date": "datetime",
        "description": "string",
        "amount": "decimal"
      }
    ]
  }
  ```
- **Errors:** 403 Unauthorized, 404 Not Found

## 2. Transfer Funds to Youth Account
- **Endpoint:** POST /api/youth-accounts/{youthAccountId}/fund-transfer
- **Auth:** OAuth2 token (parent)
- **Request:**
  ```json
  {
    "sourceAccountId": "string",
    "transferAmount": "decimal",
    "currency": "string"
  }
  ```
- **Response:**
  ```json
  {
    "transferId": "string",
    "status": "SUCCESS|FAILED",
    "updatedBalance": "decimal"
  }
  ```
- **Errors:** 400 Bad Request (validation), 400 Insufficient Funds, 403 Unauthorized, 500 Transfer Error

## 3. Configure Weekly Spending Limit
- **Endpoint:** PUT /api/youth-accounts/{youthAccountId}/spending-limit
- **Auth:** OAuth2 token (parent)
- **Request:**
  ```json
  {
    "weeklyLimit": "decimal"
  }
  ```
- **Response:**
  ```json
  {
    "youthAccountId": "string",
    "weeklyLimit": "decimal",
    "status": "UPDATED"
  }
  ```
- **Errors:** 400 Validation Error, 403 Unauthorized, 404 Not Found

## 4. Retrieve Youth Account Transaction History
- **Endpoint:** GET /api/youth-accounts/{youthAccountId}/transactions?startDate&endDate&page&pageSize
- **Auth:** OAuth2 token (parent)
- **Request:** Query params: startDate, endDate, page, pageSize
- **Response:**
  ```json
  {
    "transactions": [
      {
        "transactionId": "string",
        "date": "datetime",
        "merchant": "string",
        "amount": "decimal",
        "transactionType": "debit|credit"
      }
    ],
    "pagination": {
      "page": "number",
      "pageSize": "number",
      "totalRecords": "number"
    }
  }
  ```
- **Errors:** 400 Bad Request, 403 Unauthorized, 404 Not Found

## 5. General Error Handling
- **Standard Error Response:**
  ```json
  {
    "errorCode": "string",
    "message": "string",
    "details": "object"
  }
  ```
- **Common Error Codes:**
  - 400 Validation Error
  - 401 Unauthorized
  - 403 Forbidden
  - 404 Not Found
  - 409 Conflict
  - 500 Internal Server Error

## 6. Security/Compliance
- All endpoints require OAuth2 access token
- RBAC enforced (parent can only access their youth accounts)
- Input validation, output filtering, audit logging for all APIs
