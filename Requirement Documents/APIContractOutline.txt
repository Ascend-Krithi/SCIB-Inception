API Contract Outline

Endpoint: GET /api/youth-accounts/{youthAccountId}/dashboard
- Description: Retrieve youth account dashboard details
- Request: Path param youthAccountId
- Response:
  {
    "youthAccountId": "string",
    "accountBalance": "decimal",
    "spendingLimit": "decimal",
    "currency": "string",
    "recentTransactions": [
      {
        "transactionId": "string",
        "date": "datetime",
        "description": "string",
        "amount": "decimal"
      }
    ]
  }
- Error Handling: 403 Unauthorized, 404 Not Found

Endpoint: POST /api/youth-accounts/{youthAccountId}/fund-transfer
- Description: Transfer funds from parent to youth account
- Request:
  {
    "sourceAccountId": "string",
    "transferAmount": "decimal",
    "currency": "string"
  }
- Response:
  {
    "transferId": "string",
    "status": "SUCCESS",
    "updatedBalance": "decimal"
  }
- Error Handling: 400 Insufficient funds, 400 Invalid account, 500 Service failure

Endpoint: PUT /api/youth-accounts/{youthAccountId}/spending-limit
- Description: Configure weekly spending limit
- Request:
  {
    "weeklyLimit": "decimal"
  }
- Response:
  {
    "youthAccountId": "string",
    "weeklyLimit": "decimal",
    "status": "UPDATED"
  }
- Error Handling: 400 Invalid value, 403 Unauthorized

Endpoint: GET /api/youth-accounts/{youthAccountId}/transactions
- Description: Retrieve transaction history
- Request: Query params startDate, endDate, page, pageSize
- Response:
  {
    "transactions": [
      {
        "transactionId": "string",
        "date": "datetime",
        "merchant": "string",
        "amount": "decimal",
        "transactionType": "debit | credit"
      }
    ],
    "pagination": {
      "page": "number",
      "pageSize": "number",
      "totalRecords": "number"
    }
  }
- Error Handling: 403 Unauthorized, 404 Not Found

Authentication: OAuth2 token required for all endpoints
Authorization: Parent RBAC enforced
Error Handling: OpenAPI-standard error responses
