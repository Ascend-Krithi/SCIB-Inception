API Contract Outline

1. Endpoint: GET /api/youth-accounts/{youthAccountId}/dashboard
   - Description: Retrieve youth account dashboard details
   - Request: Path param youthAccountId
   - Response:
     {
       "youthAccountId": "string",
       "accountBalance": "decimal",
       "spendingLimit": "decimal",
       "currency": "string",
       "recentTransactions": [
         {
           "transactionId": "string",
           "date": "datetime",
           "description": "string",
           "amount": "decimal"
         }
       ]
     }
   - Error Handling:
     - 403 Forbidden (unauthorized)
     - 404 Not Found (invalid account)

2. Endpoint: POST /api/youth-accounts/{youthAccountId}/fund-transfer
   - Description: Transfer funds from parent to youth account
   - Request:
     {
       "sourceAccountId": "string",
       "transferAmount": "decimal",
       "currency": "string"
     }
   - Response:
     {
       "transferId": "string",
       "status": "SUCCESS",
       "updatedBalance": "decimal"
     }
   - Error Handling:
     - 400 Bad Request (insufficient funds, invalid mapping)
     - 500 Internal Server Error (service failure)

3. Endpoint: PUT /api/youth-accounts/{youthAccountId}/spending-limit
   - Description: Configure weekly spending limit
   - Request:
     {
       "weeklyLimit": "decimal"
     }
   - Response:
     {
       "youthAccountId": "string",
       "weeklyLimit": "decimal",
       "status": "UPDATED"
     }
   - Error Handling:
     - 400 Bad Request (validation error)
     - 403 Forbidden (unauthorized)

4. Endpoint: GET /api/youth-accounts/{youthAccountId}/transactions
   - Description: Retrieve transaction history
   - Query Params: startDate, endDate, page, pageSize
   - Response:
     {
       "transactions": [
         {
           "transactionId": "string",
           "date": "datetime",
           "merchant": "string",
           "amount": "decimal",
           "transactionType": "debit | credit"
         }
       ],
       "pagination": {
         "page": "number",
         "pageSize": "number",
         "totalRecords": "number"
       }
     }
   - Error Handling:
     - 403 Forbidden (unauthorized)
     - 404 Not Found (invalid account)

Security:
- OAuth2 token required on all endpoints
- RBAC: Only parent/guardian of youth account can access/modify
- All responses in application/json
