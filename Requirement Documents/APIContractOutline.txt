API Contract Outline
====================

1. Endpoint: GET /api/youth-accounts/{youthAccountId}/dashboard
   - Description: Retrieve youth account dashboard (balance, limit, recent transactions)
   - Request: Path param youthAccountId
   - Response:
     {
       "youthAccountId": "string",
       "accountBalance": "decimal",
       "spendingLimit": "decimal",
       "currency": "string",
       "recentTransactions": [
         {
           "transactionId": "string",
           "date": "datetime",
           "description": "string",
           "amount": "decimal"
         }
       ]
     }
   - Security: OAuth2, parent must own youth account
   - Error Handling:
     - 403 Forbidden (not authorized)
     - 404 Not Found (invalid account)
     - 500 Internal Server Error

2. Endpoint: POST /api/youth-accounts/{youthAccountId}/fund-transfer
   - Description: Transfer funds from parent to youth account
   - Request:
     {
       "sourceAccountId": "string",
       "transferAmount": "decimal",
       "currency": "string"
     }
   - Response:
     {
       "transferId": "string",
       "status": "SUCCESS",
       "updatedBalance": "decimal"
     }
   - Security: OAuth2, validate parent ownership and sufficient funds
   - Error Handling:
     - 400 Bad Request (insufficient funds, invalid input)
     - 404 Not Found (invalid account)
     - 500 Internal Server Error

3. Endpoint: PUT /api/youth-accounts/{youthAccountId}/spending-limit
   - Description: Configure weekly spending limit for youth account
   - Request:
     {
       "weeklyLimit": "decimal"
     }
   - Response:
     {
       "youthAccountId": "string",
       "weeklyLimit": "decimal",
       "status": "UPDATED"
     }
   - Security: OAuth2, validate parent ownership
   - Error Handling:
     - 400 Bad Request (invalid limit)
     - 404 Not Found (invalid account)
     - 500 Internal Server Error

4. Endpoint: GET /api/youth-accounts/{youthAccountId}/transactions
   - Description: Retrieve youth account transaction history
   - Request:
     - Query params: startDate, endDate, page, pageSize
   - Response:
     {
       "transactions": [
         {
           "transactionId": "string",
           "date": "datetime",
           "merchant": "string",
           "amount": "decimal",
           "transactionType": "debit | credit"
         }
       ],
       "pagination": {
         "page": "number",
         "pageSize": "number",
         "totalRecords": "number"
       }
     }
   - Security: OAuth2, parent must own youth account
   - Error Handling:
     - 403 Forbidden (not authorized)
     - 404 Not Found (invalid account)
     - 500 Internal Server Error

5. General API Considerations
   - All endpoints return errors as:
     {
       "errorCode": "string",
       "message": "string",
       "details": "string (optional)"
     }
   - Input validation, output filtering, audit logging, and RBAC enforced
