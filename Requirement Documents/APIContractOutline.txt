API Contract Outline

1. GET /api/youth-accounts/{youthAccountId}/dashboard
- Method: GET
- Request: Path param youthAccountId
- Response:
  {
    "youthAccountId": "string",
    "accountBalance": "decimal",
    "spendingLimit": "decimal",
    "currency": "string",
    "recentTransactions": [
      { "transactionId": "string", "date": "datetime", "description": "string", "amount": "decimal" }
    ]
  }
- Errors: 403 Unauthorized, 404 Not Found

2. POST /api/youth-accounts/{youthAccountId}/fund-transfer
- Method: POST
- Request:
  {
    "sourceAccountId": "string",
    "transferAmount": "decimal",
    "currency": "string"
  }
- Response:
  {
    "transferId": "string",
    "status": "SUCCESS",
    "updatedBalance": "decimal"
  }
- Errors: 400 Insufficient funds, 400 Invalid account, 500 Transfer failure

3. PUT /api/youth-accounts/{youthAccountId}/spending-limit
- Method: PUT
- Request:
  {
    "weeklyLimit": "decimal"
  }
- Response:
  {
    "youthAccountId": "string",
    "weeklyLimit": "decimal",
    "status": "UPDATED"
  }
- Errors: 400 Validation error, 403 Unauthorized

4. GET /api/youth-accounts/{youthAccountId}/transactions
- Method: GET
- Query params: startDate, endDate, page, pageSize
- Response:
  {
    "transactions": [
      { "transactionId": "string", "date": "datetime", "merchant": "string", "amount": "decimal", "transactionType": "debit | credit" }
    ],
    "pagination": { "page": "number", "pageSize": "number", "totalRecords": "number" }
  }
- Errors: 403 Unauthorized, 404 Not Found

General:
- All endpoints: OAuth2 Bearer token required
- RBAC: Only parent/guardian can manage youth account
- Standard error response:
  {
    "error": "string",
    "message": "string"
  }
