API Contract Outline

1. Endpoint: GET /api/youth-accounts/{youthAccountId}/dashboard
- Description: Retrieve youth account dashboard details
- Request: Path param youthAccountId
- Response:
  {
    "youthAccountId": "string",
    "accountBalance": "decimal",
    "spendingLimit": "decimal",
    "currency": "string",
    "recentTransactions": [
      {
        "transactionId": "string",
        "date": "datetime",
        "description": "string",
        "amount": "decimal"
      }
    ]
  }
- Error Handling: 403 Unauthorized, 404 Not Found

2. Endpoint: POST /api/youth-accounts/{youthAccountId}/fund-transfer
- Description: Transfer funds from parent account to youth account
- Request Body:
  {
    "sourceAccountId": "string",
    "transferAmount": "decimal",
    "currency": "string"
  }
- Response:
  {
    "transferId": "string",
    "status": "SUCCESS",
    "updatedBalance": "decimal"
  }
- Error Handling: 400 Insufficient balance, 400 Invalid mapping, 500 Transfer service failure

3. Endpoint: PUT /api/youth-accounts/{youthAccountId}/spending-limit
- Description: Configure weekly spending limit
- Request Body:
  {
    "weeklyLimit": "decimal"
  }
- Response:
  {
    "youthAccountId": "string",
    "weeklyLimit": "decimal",
    "status": "UPDATED"
  }
- Error Handling: 400 Validation error

4. Endpoint: GET /api/youth-accounts/{youthAccountId}/transactions
- Description: Retrieve transaction history
- Query Parameters: startDate, endDate, page, pageSize
- Response:
  {
    "transactions": [
      {
        "transactionId": "string",
        "date": "datetime",
        "merchant": "string",
        "amount": "decimal",
        "transactionType": "debit | credit"
      }
    ],
    "pagination": {
      "page": "number",
      "pageSize": "number",
      "totalRecords": "number"
    }
  }
- Error Handling: 403 Unauthorized, 404 Not Found

Common Error Handling:
- 400 Bad Request (input validation)
- 403 Forbidden (RBAC)
- 404 Not Found
- 500 Internal Server Error

Authentication:
- OAuth 2.0 required for all endpoints
- Parent ownership validated
