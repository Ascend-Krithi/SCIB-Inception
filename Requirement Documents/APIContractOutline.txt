API Contract Outline

1. Dashboard API
Endpoint: GET /api/youth-accounts/{youthAccountId}/dashboard
Request: OAuth token, youthAccountId (path)
Response:
{
  "youthAccountId": "string",
  "accountBalance": "decimal",
  "spendingLimit": "decimal",
  "currency": "string",
  "recentTransactions": [
    {
      "transactionId": "string",
      "date": "datetime",
      "description": "string",
      "amount": "decimal"
    }
  ]
}
Error Handling:
- 403 Unauthorized
- 404 Not Found
- 500 Internal Error

2. Fund Transfer API
Endpoint: POST /api/youth-accounts/{youthAccountId}/fund-transfer
Request:
{
  "sourceAccountId": "string",
  "transferAmount": "decimal",
  "currency": "string"
}
Response:
{
  "transferId": "string",
  "status": "SUCCESS",
  "updatedBalance": "decimal"
}
Error Handling:
- 400 Insufficient Funds
- 400 Invalid Account Mapping
- 500 Transfer Service Failure

3. Spending Limit Configuration API
Endpoint: PUT /api/youth-accounts/{youthAccountId}/spending-limit
Request:
{
  "weeklyLimit": "decimal"
}
Response:
{
  "youthAccountId": "string",
  "weeklyLimit": "decimal",
  "status": "UPDATED"
}
Error Handling:
- 400 Validation Error
- 403 Unauthorized
- 500 Internal Error

4. Transaction History API
Endpoint: GET /api/youth-accounts/{youthAccountId}/transactions
Query Parameters:
- startDate
- endDate
- page
- pageSize
Response:
{
  "transactions": [
    {
      "transactionId": "string",
      "date": "datetime",
      "merchant": "string",
      "amount": "decimal",
      "transactionType": "debit | credit"
    }
  ],
  "pagination": {
    "page": "number",
    "pageSize": "number",
    "totalRecords": "number"
  }
}
Error Handling:
- 403 Unauthorized
- 400 Invalid Parameters
- 500 Internal Error


Common Aspects:
- All endpoints require OAuth token in Authorization header
- Parent ownership of youth account validated for all operations
- API responds with structured error objects:
  {
    "errorCode": "string",
    "message": "string",
    "details": "string"
  }
- OpenAPI 3.0 schema definitions reused across endpoints
