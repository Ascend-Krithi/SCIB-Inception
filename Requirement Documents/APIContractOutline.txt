API Contract Outline

1. Endpoint: GET /api/youth-accounts/{youthAccountId}/dashboard
   - Description: Retrieve dashboard details
   - Request: Path param youthAccountId
   - Response:
     {
       "youthAccountId": "string",
       "accountBalance": "decimal",
       "spendingLimit": "decimal",
       "currency": "string",
       "recentTransactions": [
         {
           "transactionId": "string",
           "date": "datetime",
           "description": "string",
           "amount": "decimal"
         }
       ]
     }
   - Error Handling:
     403 Unauthorized, 404 Not Found, 500 Internal Error

2. Endpoint: POST /api/youth-accounts/{youthAccountId}/fund-transfer
   - Description: Transfer funds from parent to youth account
   - Request:
     {
       "sourceAccountId": "string",
       "transferAmount": "decimal",
       "currency": "string"
     }
   - Response:
     {
       "transferId": "string",
       "status": "SUCCESS",
       "updatedBalance": "decimal"
     }
   - Error Handling:
     400 Insufficient funds, 400 Invalid mapping, 500 Transfer failure

3. Endpoint: PUT /api/youth-accounts/{youthAccountId}/spending-limit
   - Description: Set weekly spending limit
   - Request:
     {
       "weeklyLimit": "decimal"
     }
   - Response:
     {
       "youthAccountId": "string",
       "weeklyLimit": "decimal",
       "status": "UPDATED"
     }
   - Error Handling:
     400 Validation error, 403 Unauthorized

4. Endpoint: GET /api/youth-accounts/{youthAccountId}/transactions
   - Description: Retrieve transaction history
   - Request: Query params startDate, endDate, page, pageSize
   - Response:
     {
       "transactions": [
         {
           "transactionId": "string",
           "date": "datetime",
           "merchant": "string",
           "amount": "decimal",
           "transactionType": "debit | credit"
         }
       ],
       "pagination": {
         "page": "number",
         "pageSize": "number",
         "totalRecords": "number"
       }
     }
   - Error Handling:
     403 Unauthorized, 404 Not Found

Security:
- OAuth token validation required for all endpoints
- RBAC enforced (parent must own youth account)
- Input validation and audit logging

OpenAPI/Swagger:
- All endpoints documented (see SCIB-30)
- Schema definitions reusable
