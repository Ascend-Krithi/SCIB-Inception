API Contract Outline

1. Endpoint: GET /api/youth-accounts/{youthAccountId}/dashboard
   - Description: Retrieve dashboard details (balance, spending limit, recent transactions)
   - Request: Path param youthAccountId
   - Response:
     {
       "youthAccountId": "string",
       "accountBalance": "decimal",
       "spendingLimit": "decimal",
       "currency": "string",
       "recentTransactions": [
         {
           "transactionId": "string",
           "date": "datetime",
           "description": "string",
           "amount": "decimal"
         }
       ]
     }
   - Security: OAuth2, RBAC (parent must own youth account)
   - Errors: 403 Unauthorized, 404 Not Found, 500 Internal Error

2. Endpoint: POST /api/youth-accounts/{youthAccountId}/fund-transfer
   - Description: Transfer funds from parent to youth account
   - Request:
     {
       "sourceAccountId": "string",
       "transferAmount": "decimal",
       "currency": "string"
     }
   - Response:
     {
       "transferId": "string",
       "status": "SUCCESS",
       "updatedBalance": "decimal"
     }
   - Errors: 400 Insufficient balance, 400 Invalid account, 500 Service error

3. Endpoint: PUT /api/youth-accounts/{youthAccountId}/spending-limit
   - Description: Set or update weekly spending limit
   - Request:
     {
       "weeklyLimit": "decimal"
     }
   - Response:
     {
       "youthAccountId": "string",
       "weeklyLimit": "decimal",
       "status": "UPDATED"
     }
   - Errors: 400 Validation error, 403 Unauthorized

4. Endpoint: GET /api/youth-accounts/{youthAccountId}/transactions
   - Description: Retrieve transaction history
   - Query Params: startDate, endDate, page, pageSize
   - Response:
     {
       "transactions": [
         {
           "transactionId": "string",
           "date": "datetime",
           "merchant": "string",
           "amount": "decimal",
           "transactionType": "debit | credit"
         }
       ],
       "pagination": {
         "page": "number",
         "pageSize": "number",
         "totalRecords": "number"
       }
     }
   - Errors: 403 Unauthorized, 404 Not Found

Error Handling (all APIs):
- 400: Validation errors, insufficient funds, invalid parameters
- 403: Unauthorized (RBAC, parent ownership)
- 404: Not found (account, transaction)
- 409: Conflict (concurrent modification)
- 500: Internal server error

All endpoints require OAuth2 token, RBAC enforced for parent access.
