API Contract Outline

Endpoint: GET /api/youth-accounts/{youthAccountId}/dashboard
- Description: Retrieve youth account dashboard details
- Request Params: youthAccountId (path)
- Response:
  {
    "youthAccountId": "string",
    "accountBalance": "decimal",
    "spendingLimit": "decimal",
    "currency": "string",
    "recentTransactions": [
      {
        "transactionId": "string",
        "date": "datetime",
        "description": "string",
        "amount": "decimal"
      }
    ]
  }
- Error Handling: 403 Forbidden (unauthorized), 404 Not Found

Endpoint: POST /api/youth-accounts/{youthAccountId}/fund-transfer
- Description: Transfer funds from parent to youth account
- Request Body:
  {
    "sourceAccountId": "string",
    "transferAmount": "decimal",
    "currency": "string"
  }
- Response:
  {
    "transferId": "string",
    "status": "SUCCESS",
    "updatedBalance": "decimal"
  }
- Error Handling: 400 Bad Request (insufficient funds, invalid mapping), 500 Internal Error

Endpoint: PUT /api/youth-accounts/{youthAccountId}/spending-limit
- Description: Configure weekly spending limit
- Request Body:
  {
    "weeklyLimit": "decimal"
  }
- Response:
  {
    "youthAccountId": "string",
    "weeklyLimit": "decimal",
    "status": "UPDATED"
  }
- Error Handling: 400 Bad Request (validation error), 403 Forbidden

Endpoint: GET /api/youth-accounts/{youthAccountId}/transactions
- Description: Retrieve youth account transaction history
- Query Params: startDate, endDate, page, pageSize
- Response:
  {
    "transactions": [
      {
        "transactionId": "string",
        "date": "datetime",
        "merchant": "string",
        "amount": "decimal",
        "transactionType": "debit | credit"
      }
    ],
    "pagination": {
      "page": "number",
      "pageSize": "number",
      "totalRecords": "number"
    }
  }
- Error Handling: 403 Forbidden (unauthorized), 400 Bad Request (invalid date), 404 Not Found

Authentication: OAuth token required for all endpoints
RBAC: Parent role required for youth account APIs
Audit Logging: All API actions logged
Input Validation: All request fields validated
