API Contract Outline

1. GET /api/youth-accounts/{youthAccountId}/dashboard
- Description: Retrieve youth account dashboard details
- Request: Path param youthAccountId
- Response:
  {
    "youthAccountId": "string",
    "accountBalance": "decimal",
    "spendingLimit": "decimal",
    "currency": "string",
    "recentTransactions": [
      {
        "transactionId": "string",
        "date": "datetime",
        "description": "string",
        "amount": "decimal"
      }
    ]
  }
- Error Handling: 403 Unauthorized, 404 Not Found, 500 Internal Error

2. POST /api/youth-accounts/{youthAccountId}/fund-transfer
- Description: Transfer funds from parent account to youth account
- Request:
  {
    "sourceAccountId": "string",
    "transferAmount": "decimal",
    "currency": "string"
  }
- Response:
  {
    "transferId": "string",
    "status": "SUCCESS",
    "updatedBalance": "decimal"
  }
- Error Handling: 400 Insufficient Balance, 400 Invalid Account, 500 Transfer Service Failure

3. PUT /api/youth-accounts/{youthAccountId}/spending-limit
- Description: Set weekly spending limit for youth account
- Request:
  {
    "weeklyLimit": "decimal"
  }
- Response:
  {
    "youthAccountId": "string",
    "weeklyLimit": "decimal",
    "status": "UPDATED"
  }
- Error Handling: 400 Validation Error, 403 Unauthorized

4. GET /api/youth-accounts/{youthAccountId}/transactions
- Description: Retrieve transaction history for youth account
- Request: Query params startDate, endDate, page, pageSize
- Response:
  {
    "transactions": [
      {
        "transactionId": "string",
        "date": "datetime",
        "merchant": "string",
        "amount": "decimal",
        "transactionType": "debit | credit"
      }
    ],
    "pagination": {
      "page": "number",
      "pageSize": "number",
      "totalRecords": "number"
    }
  }
- Error Handling: 403 Unauthorized, 400 Invalid Params

Security, Auth, and Compliance:
- OAuth2 Bearer token required
- RBAC enforced (parent must own youth account)
- Audit logging for all fund transfers, limit changes
- Input validation, output filtering
