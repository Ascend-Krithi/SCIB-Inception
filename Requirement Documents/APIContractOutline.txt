API Contract Outline

1. Endpoint: GET /api/youth-accounts/{youthAccountId}/dashboard
- Description: Retrieve youth account dashboard details
- Request: Path param youthAccountId
- Response:
{
  "youthAccountId": "string",
  "accountBalance": "decimal",
  "spendingLimit": "decimal",
  "currency": "string",
  "recentTransactions": [
    {
      "transactionId": "string",
      "date": "datetime",
      "description": "string",
      "amount": "decimal"
    }
  ]
}
- Error Handling: 403 Unauthorized, 404 Not Found, 500 Internal Error

2. Endpoint: POST /api/youth-accounts/{youthAccountId}/fund-transfer
- Description: Transfer funds from parent account to youth account
- Request:
{
  "sourceAccountId": "string",
  "transferAmount": "decimal",
  "currency": "string"
}
- Response:
{
  "transferId": "string",
  "status": "SUCCESS",
  "updatedBalance": "decimal"
}
- Error Handling: 400 Insufficient funds, 400 Invalid account, 500 Transfer failure

3. Endpoint: PUT /api/youth-accounts/{youthAccountId}/spending-limit
- Description: Configure weekly spending limit
- Request:
{
  "weeklyLimit": "decimal"
}
- Response:
{
  "youthAccountId": "string",
  "weeklyLimit": "decimal",
  "status": "UPDATED"
}
- Error Handling: 400 Validation error, 403 Unauthorized, 500 Internal Error

4. Endpoint: GET /api/youth-accounts/{youthAccountId}/transactions
- Description: Retrieve youth account transaction history
- Request: Query params startDate, endDate, page, pageSize
- Response:
{
  "transactions": [
    {
      "transactionId": "string",
      "date": "datetime",
      "merchant": "string",
      "amount": "decimal",
      "transactionType": "debit | credit"
    }
  ],
  "pagination": {
    "page": "number",
    "pageSize": "number",
    "totalRecords": "number"
  }
}
- Error Handling: 403 Unauthorized, 400 Invalid params, 500 Internal Error

Security and Compliance:
- OAuth2 Bearer token required for all endpoints
- RBAC enforced: Parent must own youth account
- Audit logging for all transactions and limit changes
- Input validation on all request parameters and bodies
- Output filtering to prevent data leaks
