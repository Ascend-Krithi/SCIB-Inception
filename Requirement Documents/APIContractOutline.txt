API Contract Outline

1. Endpoint: GET /api/youth-accounts/{youthAccountId}/dashboard
   - Description: Retrieve youth account dashboard (balance, limit, recent transactions)
   - Request: Path param youthAccountId
   - Response:
     {
       "youthAccountId": "string",
       "accountBalance": "decimal",
       "spendingLimit": "decimal",
       "currency": "string",
       "recentTransactions": [
         {
           "transactionId": "string",
           "date": "datetime",
           "description": "string",
           "amount": "decimal"
         }
       ]
     }
   - Errors: 403 Unauthorized, 404 Not Found, 500 Internal Server Error

2. Endpoint: POST /api/youth-accounts/{youthAccountId}/fund-transfer
   - Description: Transfer funds from parent to youth account
   - Request:
     {
       "sourceAccountId": "string",
       "transferAmount": "decimal",
       "currency": "string"
     }
   - Response:
     {
       "transferId": "string",
       "status": "SUCCESS|FAILED",
       "updatedBalance": "decimal"
     }
   - Errors: 400 Bad Request (insufficient funds/invalid mapping), 403 Unauthorized, 500 Internal Server Error

3. Endpoint: PUT /api/youth-accounts/{youthAccountId}/spending-limit
   - Description: Set weekly spending limit
   - Request:
     {
       "weeklyLimit": "decimal"
     }
   - Response:
     {
       "youthAccountId": "string",
       "weeklyLimit": "decimal",
       "status": "UPDATED"
     }
   - Errors: 400 Bad Request (invalid value), 403 Unauthorized, 500 Internal Server Error

4. Endpoint: GET /api/youth-accounts/{youthAccountId}/transactions
   - Description: Retrieve youth account transaction history
   - Query params: startDate, endDate, page, pageSize
   - Response:
     {
       "transactions": [
         {
           "transactionId": "string",
           "date": "datetime",
           "merchant": "string",
           "amount": "decimal",
           "transactionType": "debit|credit"
         }
       ],
       "pagination": {
         "page": "number",
         "pageSize": "number",
         "totalRecords": "number"
       }
     }
   - Errors: 403 Unauthorized, 404 Not Found, 500 Internal Server Error

Security & Compliance:
- All endpoints require OAuth 2.0 Bearer token
- RBAC: Only parent/guardian can manage youth accounts
- Input validation, output filtering, audit logging enforced
