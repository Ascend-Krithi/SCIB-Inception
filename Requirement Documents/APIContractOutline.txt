API Contract Outline

1. Dashboard API
Endpoint: GET /api/youth-accounts/{youthAccountId}/dashboard
Request: Path param youthAccountId
Response:
{
  "youthAccountId": "string",
  "accountBalance": "decimal",
  "spendingLimit": "decimal",
  "currency": "string",
  "recentTransactions": [
    {
      "transactionId": "string",
      "date": "datetime",
      "description": "string",
      "amount": "decimal"
    }
  ]
}
Error Handling: 403 Unauthorized, 404 Not Found

2. Fund Transfer API
Endpoint: POST /api/youth-accounts/{youthAccountId}/fund-transfer
Request Body:
{
  "sourceAccountId": "string",
  "transferAmount": "decimal",
  "currency": "string"
}
Response:
{
  "transferId": "string",
  "status": "SUCCESS",
  "updatedBalance": "decimal"
}
Error Handling: 400 Insufficient Funds, 400 Invalid Mapping, 500 Transfer Failure

3. Spending Limit API
Endpoint: PUT /api/youth-accounts/{youthAccountId}/spending-limit
Request Body:
{
  "weeklyLimit": "decimal"
}
Response:
{
  "youthAccountId": "string",
  "weeklyLimit": "decimal",
  "status": "UPDATED"
}
Error Handling: 400 Validation Error, 403 Unauthorized

4. Transaction History API
Endpoint: GET /api/youth-accounts/{youthAccountId}/transactions
Query Params: startDate, endDate, page, pageSize
Response:
{
  "transactions": [
    {
      "transactionId": "string",
      "date": "datetime",
      "merchant": "string",
      "amount": "decimal",
      "transactionType": "debit | credit"
    }
  ],
  "pagination": {
    "page": "number",
    "pageSize": "number",
    "totalRecords": "number"
  }
}
Error Handling: 403 Unauthorized, 404 Not Found

Authentication: OAuth 2.0 required for all endpoints
RBAC: Parent must own youth account
Input Validation: All request schemas validated
Audit Logging: All API actions logged with user and timestamp
