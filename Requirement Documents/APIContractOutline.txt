API Contract Outline

1. Endpoint: GET /api/youth-accounts/{youthAccountId}/dashboard
   - Description: Retrieve youth account dashboard details
   - Request Params: youthAccountId (path)
   - Response Schema:
     {
       "youthAccountId": "string",
       "accountBalance": "decimal",
       "spendingLimit": "decimal",
       "currency": "string",
       "recentTransactions": [
         {
           "transactionId": "string",
           "date": "datetime",
           "description": "string",
           "amount": "decimal"
         }
       ]
     }
   - Error Handling:
     - 403 Unauthorized (ownership validation)
     - 404 Not Found
     - 500 Internal Error

2. Endpoint: POST /api/youth-accounts/{youthAccountId}/fund-transfer
   - Description: Transfer funds from parent to youth account
   - Request Params: youthAccountId (path)
   - Request Body:
     {
       "sourceAccountId": "string",
       "transferAmount": "decimal",
       "currency": "string"
     }
   - Response Schema:
     {
       "transferId": "string",
       "status": "SUCCESS",
       "updatedBalance": "decimal"
     }
   - Error Handling:
     - 400 Insufficient balance
     - 400 Invalid account mapping
     - 500 Transfer service failure

3. Endpoint: PUT /api/youth-accounts/{youthAccountId}/spending-limit
   - Description: Configure weekly spending limit
   - Request Params: youthAccountId (path)
   - Request Body:
     {
       "weeklyLimit": "decimal"
     }
   - Response Schema:
     {
       "youthAccountId": "string",
       "weeklyLimit": "decimal",
       "status": "UPDATED"
     }
   - Error Handling:
     - 400 Validation error (invalid value)
     - 403 Unauthorized
     - 500 Internal Error

4. Endpoint: GET /api/youth-accounts/{youthAccountId}/transactions
   - Description: Retrieve youth account transaction history
   - Request Params: youthAccountId (path), startDate, endDate, page, pageSize (query)
   - Response Schema:
     {
       "transactions": [
         {
           "transactionId": "string",
           "date": "datetime",
           "merchant": "string",
           "amount": "decimal",
           "transactionType": "debit | credit"
         }
       ],
       "pagination": {
         "page": "number",
         "pageSize": "number",
         "totalRecords": "number"
       }
     }
   - Error Handling:
     - 403 Unauthorized
     - 404 Not Found
     - 500 Internal Error
