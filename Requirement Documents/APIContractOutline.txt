# API Contract Outline: Youth Account Management

## 1. Retrieve Youth Account Dashboard
- **Endpoint:** GET /api/youth-accounts/{youthAccountId}/dashboard
- **Request:** Path param youthAccountId
- **Response:**
  ```json
  {
    "youthAccountId": "string",
    "accountBalance": "decimal",
    "spendingLimit": "decimal",
    "currency": "string",
    "recentTransactions": [
      {
        "transactionId": "string",
        "date": "datetime",
        "description": "string",
        "amount": "decimal"
      }
    ]
  }
  ```
- **Error Handling:**
  - 403 Unauthorized (invalid parent)
  - 404 Not Found (account)
  - 500 Server Error

## 2. Fund Transfer to Youth Account
- **Endpoint:** POST /api/youth-accounts/{youthAccountId}/fund-transfer
- **Request:**
  ```json
  {
    "sourceAccountId": "string",
    "transferAmount": "decimal",
    "currency": "string"
  }
  ```
- **Response:**
  ```json
  {
    "transferId": "string",
    "status": "SUCCESS",
    "updatedBalance": "decimal"
  }
  ```
- **Error Handling:**
  - 400 Insufficient funds, invalid mapping
  - 403 Unauthorized
  - 500 Transfer service failure

## 3. Configure Weekly Spending Limit
- **Endpoint:** PUT /api/youth-accounts/{youthAccountId}/spending-limit
- **Request:**
  ```json
  {
    "weeklyLimit": "decimal"
  }
  ```
- **Response:**
  ```json
  {
    "youthAccountId": "string",
    "weeklyLimit": "decimal",
    "status": "UPDATED"
  }
  ```
- **Error Handling:**
  - 400 Validation error (invalid value)
  - 403 Unauthorized
  - 404 Not Found (account)

## 4. Retrieve Transaction History
- **Endpoint:** GET /api/youth-accounts/{youthAccountId}/transactions
- **Query Params:** startDate, endDate, page, pageSize
- **Response:**
  ```json
  {
    "transactions": [
      {
        "transactionId": "string",
        "date": "datetime",
        "merchant": "string",
        "amount": "decimal",
        "transactionType": "debit | credit"
      }
    ],
    "pagination": {
      "page": "number",
      "pageSize": "number",
      "totalRecords": "number"
    }
  }
  ```
- **Error Handling:**
  - 403 Unauthorized
  - 404 Not Found
  - 500 Server Error

## 5. Common API Features
- OAuth 2.0 Bearer token required
- RBAC enforced (parent must own youth account)
- Input validation (type, range, format)
- Output filtering (sensitive data masked)
- All actions audit-logged
- Standard error response:
  ```json
  {
    "error": {
      "code": "string",
      "message": "string"
    }
  }
  ```
