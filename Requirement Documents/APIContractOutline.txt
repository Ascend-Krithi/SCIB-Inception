API Contract Outline: Youth Account Management

1. Endpoint: GET /api/youth-accounts/{youthAccountId}/dashboard
   - Description: Retrieve youth account dashboard details
   - Security: OAuth2, parent must own youth account
   - Response Schema:
     {
       "youthAccountId": "string",
       "accountBalance": "decimal",
       "spendingLimit": "decimal",
       "currency": "string",
       "recentTransactions": [
         {
           "transactionId": "string",
           "date": "datetime",
           "description": "string",
           "amount": "decimal"
         }
       ]
     }
   - Error Handling: 403 Unauthorized, 404 Not Found

2. Endpoint: POST /api/youth-accounts/{youthAccountId}/fund-transfer
   - Description: Transfer funds from parent to youth account
   - Security: OAuth2, parent ownership validation
   - Request Schema:
     {
       "sourceAccountId": "string",
       "transferAmount": "decimal",
       "currency": "string"
     }
   - Response Schema:
     {
       "transferId": "string",
       "status": "SUCCESS|FAILED",
       "updatedBalance": "decimal"
     }
   - Error Handling: 400 Insufficient funds, 400 Invalid account, 500 Service error

3. Endpoint: PUT /api/youth-accounts/{youthAccountId}/spending-limit
   - Description: Configure weekly spending limit
   - Security: OAuth2, parent ownership validation
   - Request Schema:
     {
       "weeklyLimit": "decimal"
     }
   - Response Schema:
     {
       "youthAccountId": "string",
       "weeklyLimit": "decimal",
       "status": "UPDATED|FAILED"
     }
   - Error Handling: 400 Validation error, 403 Unauthorized

4. Endpoint: GET /api/youth-accounts/{youthAccountId}/transactions
   - Description: Retrieve youth account transaction history
   - Security: OAuth2, parent/youth access validation
   - Query Params: startDate, endDate, page, pageSize
   - Response Schema:
     {
       "transactions": [
         {
           "transactionId": "string",
           "date": "datetime",
           "merchant": "string",
           "amount": "decimal",
           "transactionType": "debit|credit"
         }
       ],
       "pagination": {
         "page": "number",
         "pageSize": "number",
         "totalRecords": "number"
       }
     }
   - Error Handling: 403 Unauthorized, 404 Not Found

5. Error Handling (Global)
   - All endpoints: 401 Unauthorized, 403 Forbidden, 404 Not Found, 422 Validation Error, 500 Internal Server Error
   - Error response format:
     {
       "errorCode": "string",
       "message": "string",
       "details": ["string"]
     }

6. Security, Compliance, and RBAC
   - All endpoints require OAuth2 tokens
   - RBAC enforced at API layer (parent/youth roles)
   - Input validation, output filtering, audit logging applied
