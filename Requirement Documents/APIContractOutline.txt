API Contract Outline

1. GET /api/youth-accounts/{youthAccountId}/dashboard
- Description: Retrieve dashboard details for a youth account
- Authentication: OAuth2 (parent)
- Request: Path param: youthAccountId
- Response:
  {
    "youthAccountId": "string",
    "accountBalance": "decimal",
    "spendingLimit": "decimal",
    "currency": "string",
    "recentTransactions": [
      {
        "transactionId": "string",
        "date": "datetime",
        "description": "string",
        "amount": "decimal"
      }
    ]
  }
- Errors:
  - 403 Unauthorized (parent does not own account)
  - 404 Not Found (invalid youthAccountId)

2. POST /api/youth-accounts/{youthAccountId}/fund-transfer
- Description: Transfer funds from parent to youth account
- Authentication: OAuth2 (parent)
- Request:
  {
    "sourceAccountId": "string",
    "transferAmount": "decimal",
    "currency": "string"
  }
- Response:
  {
    "transferId": "string",
    "status": "SUCCESS|FAILED",
    "updatedBalance": "decimal"
  }
- Errors:
  - 400 Bad Request (insufficient funds, invalid amount)
  - 403 Unauthorized
  - 404 Not Found (invalid account)

3. PUT /api/youth-accounts/{youthAccountId}/spending-limit
- Description: Set or update weekly spending limit for a youth account
- Authentication: OAuth2 (parent)
- Request:
  {
    "weeklyLimit": "decimal"
  }
- Response:
  {
    "youthAccountId": "string",
    "weeklyLimit": "decimal",
    "status": "UPDATED"
  }
- Errors:
  - 400 Bad Request (invalid value)
  - 403 Unauthorized
  - 404 Not Found

4. GET /api/youth-accounts/{youthAccountId}/transactions
- Description: Retrieve youth account transaction history
- Authentication: OAuth2 (parent)
- Request: Query params: startDate, endDate, page, pageSize
- Response:
  {
    "transactions": [
      {
        "transactionId": "string",
        "date": "datetime",
        "merchant": "string",
        "amount": "decimal",
        "transactionType": "debit|credit"
      }
    ],
    "pagination": {
      "page": "number",
      "pageSize": "number",
      "totalRecords": "number"
    }
  }
- Errors:
  - 403 Unauthorized
  - 404 Not Found

5. Error Handling (General)
- All errors return structured JSON:
  {
    "errorCode": "string",
    "message": "string",
    "details": "string (optional)"
  }
- HTTP 400: Validation errors
- HTTP 401: Authentication required
- HTTP 403: Authorization failure
- HTTP 404: Resource not found
- HTTP 500: Internal server error
