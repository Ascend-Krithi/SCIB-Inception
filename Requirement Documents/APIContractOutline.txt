    "accountBalance": "decimal",
    "spendingLimit": "decimal",
    "currency": "string",

        "amount": "decimal"
      }

- Request:
  {
    "sourceAccountId": "string",
    "transferAmount": "decimal",
    "currency": "string"
  }

  {
    "transferId": "string",
    "status": "SUCCESS",

- OAuth2 token required for all endpoints
- Ownership validation for parent accounts
- RBAC enforced
- Standard error structure: { "errorCode": "string", "errorMessage": "string" }
