API Contract Outline

--- Dashboard API ---
Endpoint: GET /api/youth-accounts/{youthAccountId}/dashboard
Request: OAuth2 Bearer Token
Response:
{
  "youthAccountId": "string",
  "accountBalance": "decimal",
  "spendingLimit": "decimal",
  "currency": "string",
  "recentTransactions": [
    {
      "transactionId": "string",
      "date": "datetime",
      "description": "string",
      "amount": "decimal"
    }
  ]
}
Error Handling:
- 403 Forbidden (unauthorized parent)
- 404 Not Found (invalid youth account)
- 500 Internal Server Error

--- Fund Transfer API ---
Endpoint: POST /api/youth-accounts/{youthAccountId}/fund-transfer
Request:
{
  "sourceAccountId": "string",
  "transferAmount": "decimal",
  "currency": "string"
}
Response:
{
  "transferId": "string",
  "status": "SUCCESS",
  "updatedBalance": "decimal"
}
Error Handling:
- 400 Bad Request (insufficient funds, invalid mapping)
- 403 Forbidden (unauthorized parent)
- 500 Internal Server Error

--- Spending Limit Configuration API ---
Endpoint: PUT /api/youth-accounts/{youthAccountId}/spending-limit
Request:
{
  "weeklyLimit": "decimal"
}
Response:
{
  "youthAccountId": "string",
  "weeklyLimit": "decimal",
  "status": "UPDATED"
}
Error Handling:
- 400 Bad Request (invalid limit)
- 403 Forbidden (unauthorized parent)
- 500 Internal Server Error

--- Transaction History API ---
Endpoint: GET /api/youth-accounts/{youthAccountId}/transactions
Query Params:
- startDate
- endDate
- page
- pageSize
Response:
{
  "transactions": [
    {
      "transactionId": "string",
      "date": "datetime",
      "merchant": "string",
      "amount": "decimal",
      "transactionType": "debit | credit"
    }
  ],
  "pagination": {
    "page": "number",
    "pageSize": "number",
    "totalRecords": "number"
  }
}
Error Handling:
- 403 Forbidden (unauthorized parent)
- 400 Bad Request (invalid params)
- 500 Internal Server Error

--- Common Error Responses ---
All endpoints return structured error:
{
  "errorCode": "string",
  "errorMessage": "string"
}

--- Security & Compliance ---
- OAuth2 token required for all endpoints
- RBAC enforced (parent can only access/manage their child’s account)
- Audit logging for all API actions
