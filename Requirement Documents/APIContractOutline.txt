API Contract Outline

1. GET /api/youth-accounts/{youthAccountId}/dashboard
- Description: Retrieve consolidated youth account dashboard
- Auth: OAuth2, parent ownership validation
- Response:
  {
    "youthAccountId": "string",
    "accountBalance": "decimal",
    "spendingLimit": "decimal",
    "currency": "string",
    "recentTransactions": [
      {
        "transactionId": "string",
        "date": "datetime",
        "description": "string",
        "amount": "decimal"
      }
    ]
  }
- Errors: 403 Unauthorized, 404 Not Found, 500 Internal Error

2. POST /api/youth-accounts/{youthAccountId}/fund-transfer
- Description: Transfer funds from parent to youth account
- Auth: OAuth2, parent ownership validation
- Request:
  {
    "sourceAccountId": "string",
    "transferAmount": "decimal",
    "currency": "string"
  }
- Response:
  {
    "transferId": "string",
    "status": "SUCCESS",
    "updatedBalance": "decimal"
  }
- Errors: 400 Insufficient funds, 400 Validation error, 500 Transfer failure

3. PUT /api/youth-accounts/{youthAccountId}/spending-limit
- Description: Set or update weekly spending limit
- Auth: OAuth2, parent ownership validation
- Request:
  {
    "weeklyLimit": "decimal"
  }
- Response:
  {
    "youthAccountId": "string",
    "weeklyLimit": "decimal",
    "status": "UPDATED"
  }
- Errors: 400 Validation error, 403 Unauthorized, 500 Internal Error

4. GET /api/youth-accounts/{youthAccountId}/transactions
- Description: Retrieve youth account transaction history
- Auth: OAuth2, parent ownership validation
- Query Params: startDate, endDate, page, pageSize
- Response:
  {
    "transactions": [
      {
        "transactionId": "string",
        "date": "datetime",
        "merchant": "string",
        "amount": "decimal",
        "transactionType": "debit | credit"
      }
    ],
    "pagination": {
      "page": "number",
      "pageSize": "number",
      "totalRecords": "number"
    }
  }
- Errors: 403 Unauthorized, 404 Not Found, 500 Internal Error

Common Error Handling:
- 400: Validation errors with descriptive message
- 401/403: Unauthorized/Forbidden
- 404: Resource not found
- 409: Conflict
- 500: Internal server error
