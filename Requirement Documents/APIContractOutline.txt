API Contract Outline

1. Retrieve Youth Account Dashboard
- Endpoint: GET /api/youth-accounts/{youthAccountId}/dashboard
- Request: Path param youthAccountId
- Response:
  {
    "youthAccountId": "string",
    "accountBalance": "decimal",
    "spendingLimit": "decimal",
    "currency": "string",
    "recentTransactions": [
      {
        "transactionId": "string",
        "date": "datetime",
        "description": "string",
        "amount": "decimal"
      }
    ]
  }
- Errors: 403 Unauthorized, 404 Not Found, 500 Internal Error

2. Fund Transfer to Youth Account
- Endpoint: POST /api/youth-accounts/{youthAccountId}/fund-transfer
- Request:
  {
    "sourceAccountId": "string",
    "transferAmount": "decimal",
    "currency": "string"
  }
- Response:
  {
    "transferId": "string",
    "status": "SUCCESS|FAILED",
    "updatedBalance": "decimal"
  }
- Errors: 400 Bad Request (insufficient funds, invalid input), 403 Unauthorized, 404 Not Found, 500 Internal Error

3. Configure Weekly Spending Limit
- Endpoint: PUT /api/youth-accounts/{youthAccountId}/spending-limit
- Request:
  {
    "weeklyLimit": "decimal"
  }
- Response:
  {
    "youthAccountId": "string",
    "weeklyLimit": "decimal",
    "status": "UPDATED|FAILED"
  }
- Errors: 400 Bad Request (invalid value), 403 Unauthorized, 404 Not Found, 500 Internal Error

4. Retrieve Youth Account Transaction History
- Endpoint: GET /api/youth-accounts/{youthAccountId}/transactions
- Query Params: startDate, endDate, page, pageSize
- Response:
  {
    "transactions": [
      {
        "transactionId": "string",
        "date": "datetime",
        "merchant": "string",
        "amount": "decimal",
        "transactionType": "debit|credit",
        "status": "COMPLETED|PENDING|FAILED"
      }
    ],
    "pagination": {
      "page": "number",
      "pageSize": "number",
      "totalRecords": "number"
    }
  }
- Errors: 400 Bad Request, 403 Unauthorized, 404 Not Found, 500 Internal Error

5. Error Handling (All APIs)
- 400: Validation errors (e.g., invalid input, insufficient funds)
- 403: Unauthorized (invalid OAuth token, RBAC failure)
- 404: Resource not found
- 409: Conflict (concurrent modification)
- 500: Internal server error
- Error response example:
  {
    "errorCode": "string",
    "message": "string",
    "details": "object"
  }

---
All endpoints require OAuth2 authentication and enforce RBAC. Input validation and audit logging are mandatory for all APIs.
