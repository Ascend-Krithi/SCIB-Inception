API Contract Outline

1. Dashboard API
- Endpoint: GET /api/youth-accounts/{youthAccountId}/dashboard
- Request Params: youthAccountId (path)
- Response:
  {
    "youthAccountId": "string",
    "accountBalance": "decimal",
    "spendingLimit": "decimal",
    "currency": "string",
    "recentTransactions": [
      {
        "transactionId": "string",
        "date": "datetime",
        "description": "string",
        "amount": "decimal"
      }
    ]
  }
- Error Handling:
  - 403 Unauthorized
  - 404 Not Found
  - 500 Internal Server Error

2. Fund Transfer API
- Endpoint: POST /api/youth-accounts/{youthAccountId}/fund-transfer
- Request Body:
  {
    "sourceAccountId": "string",
    "transferAmount": "decimal",
    "currency": "string"
  }
- Response:
  {
    "transferId": "string",
    "status": "SUCCESS|FAILURE",
    "updatedBalance": "decimal"
  }
- Error Handling:
  - 400 Insufficient funds
  - 403 Unauthorized
  - 409 Invalid account mapping
  - 500 Transfer service failure

3. Spending Limit API
- Endpoint: PUT /api/youth-accounts/{youthAccountId}/spending-limit
- Request Body:
  {
    "weeklyLimit": "decimal"
  }
- Response:
  {
    "youthAccountId": "string",
    "weeklyLimit": "decimal",
    "status": "UPDATED"
  }
- Error Handling:
  - 400 Validation error
  - 403 Unauthorized
  - 500 Internal Server Error

4. Transaction History API
- Endpoint: GET /api/youth-accounts/{youthAccountId}/transactions
- Query Params: startDate, endDate, page, pageSize
- Response:
  {
    "transactions": [
      {
        "transactionId": "string",
        "date": "datetime",
        "merchant": "string",
        "amount": "decimal",
        "transactionType": "debit|credit"
      }
    ],
    "pagination": {
      "page": "number",
      "pageSize": "number",
      "totalRecords": "number"
    }
  }
- Error Handling:
  - 403 Unauthorized
  - 404 Not Found
  - 500 Internal Server Error

Authentication: OAuth token required for all endpoints
Authorization: Parent must be owner of youth account (RBAC enforced)
Validation: Input validation, output filtering, audit logging
Compliance: All endpoints designed for GDPR, PCI-DSS, ISO 27001
