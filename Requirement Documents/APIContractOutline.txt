API Contract Outline: Youth Account Management

1. Endpoint: GET /api/youth-accounts/{youthAccountId}/dashboard
   - Description: Retrieve consolidated youth account details (balance, spending limit, recent transactions)
   - Request: Path param youthAccountId
   - Response:
     {
       "youthAccountId": "string",
       "accountBalance": "decimal",
       "spendingLimit": "decimal",
       "currency": "string",
       "recentTransactions": [
         { "transactionId": "string", "date": "datetime", "description": "string", "amount": "decimal" }
       ]
     }
   - Errors: 403 Unauthorized, 404 Not Found, 500 Internal Error

2. Endpoint: POST /api/youth-accounts/{youthAccountId}/fund-transfer
   - Description: Transfer funds from parent to youth account
   - Request Body:
     {
       "sourceAccountId": "string",
       "transferAmount": "decimal",
       "currency": "string"
     }
   - Response:
     {
       "transferId": "string",
       "status": "SUCCESS|FAILED",
       "updatedBalance": "decimal"
     }
   - Errors: 400 Bad Request (insufficient funds, invalid input), 403 Unauthorized, 409 Conflict, 500 Internal Error

3. Endpoint: PUT /api/youth-accounts/{youthAccountId}/spending-limit
   - Description: Configure weekly spending limit
   - Request Body:
     {
       "weeklyLimit": "decimal"
     }
   - Response:
     {
       "youthAccountId": "string",
       "weeklyLimit": "decimal",
       "status": "UPDATED"
     }
   - Errors: 400 Bad Request (validation), 403 Unauthorized, 500 Internal Error

4. Endpoint: GET /api/youth-accounts/{youthAccountId}/transactions
   - Description: Retrieve youth account transaction history
   - Query Params: startDate, endDate, page, pageSize
   - Response:
     {
       "transactions": [
         {
           "transactionId": "string",
           "date": "datetime",
           "merchant": "string",
           "amount": "decimal",
           "transactionType": "debit|credit"
         }
       ],
       "pagination": {
         "page": "number",
         "pageSize": "number",
         "totalRecords": "number"
       }
     }
   - Errors: 403 Unauthorized, 404 Not Found, 500 Internal Error

5. Common Error Handling
   - 400: { "error": "string", "details": "string" }
   - 403: { "error": "Unauthorized access" }
   - 404: { "error": "Resource not found" }
   - 409: { "error": "Conflict" }
   - 500: { "error": "Internal server error" }

6. Security
   - OAuth2 token required in Authorization header
   - RBAC: Only parent/guardian with account ownership may access/modify
