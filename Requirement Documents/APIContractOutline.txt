API Contract Outline

1. GET /api/youth-accounts/{youthAccountId}/dashboard
- Method: GET
- Description: Retrieves consolidated youth account dashboard information (balance, spending limit, recent transactions)
- Response:
  {
    "youthAccountId": "string",
    "accountBalance": "decimal",
    "spendingLimit": "decimal",
    "currency": "string",
    "recentTransactions": [
      {
        "transactionId": "string",
        "date": "datetime",
        "description": "string",
        "amount": "decimal"
      }
    ]
  }
- Errors: 403, 404, 500

2. POST /api/youth-accounts/{youthAccountId}/fund-transfer
- Method: POST
- Description: Transfers funds from parent account to youth account
- Request:
  {
    "sourceAccountId": "string",
    "transferAmount": "decimal",
    "currency": "string"
  }
- Response:
  {
    "transferId": "string",
    "status": "SUCCESS|FAILED",
    "updatedBalance": "decimal"
  }
- Errors: 400, 404, 500

3. PUT /api/youth-accounts/{youthAccountId}/spending-limit
- Method: PUT
- Description: Configure weekly spending limit
- Request:
  {
    "weeklyLimit": "decimal"
  }
- Response:
  {
    "youthAccountId": "string",
    "weeklyLimit": "decimal",
    "status": "UPDATED"
  }
- Errors: 400, 404, 500

4. GET /api/youth-accounts/{youthAccountId}/transactions
- Method: GET
- Description: Returns transaction history for youth account
- Query Params: startDate, endDate, page, pageSize
- Response:
  {
    "transactions": [
      {
        "transactionId": "string",
        "date": "datetime",
        "merchant": "string",
        "amount": "decimal",
        "transactionType": "debit|credit"
      }
    ],
    "pagination": {
      "page": "number",
      "pageSize": "number",
      "totalRecords": "number"
    }
  }
- Errors: 403, 404, 500

Error Schema:
{
  "errorCode": "string",
  "message": "string",
  "details": "object"
}

RBAC:
- All endpoints require OAuth2 Bearer token
- Parent must own youth account; youth may only view dashboard
- All actions are logged for audit
