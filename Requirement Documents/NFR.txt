Non-Functional Requirements (NFRs)

Security
- OAuth2 authentication for all endpoints
- RBAC for parent/youth roles
- Audit logging for fund transfers, limit changes, dashboard access
- Data encryption at rest and in transit
- Input validation and output filtering

Compliance
- GDPR: User data privacy and consent
- PCI-DSS: Secure handling of payment data
- ISO 27001: Information security controls

Performance
- API response time < 500ms under normal load
- Throughput: 1000 requests/sec with < 1% error rate

Scalability
- Horizontal scaling via Kubernetes
- Stateless APIs

Availability
- 99.99% uptime
- Automatic failover for service pods

Reliability
- Retry logic for external service calls
- Circuit breaker for service failures

Maintainability
- Modular microservices
- Clear documentation
- Automated CI/CD

Auditability
- All actions logged with user/session info
- Logs retained for 1 year

Disaster Recovery
- RTO < 4 hours
- RPO < 1 hour
- Daily backups (encrypted)

Backup
- Daily encrypted database backups
- Backup verification jobs

Monitoring
- Real-time metrics (Prometheus/Grafana)
- Alerting for error rates, latency, downtime

Logging
- Centralized log aggregation (ELK stack)
- Error and access logs

RBAC
- Roles: Parent, Youth, Admin
- Permissions enforced at API Gateway and Auth Service

Mapping to Design Decisions
- All NFRs referenced in HLD section 7, mapped to ADRs SCIB-25 to SCIB-30
