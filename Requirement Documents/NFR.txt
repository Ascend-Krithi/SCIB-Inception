
Non-Functional Requirements (NFRs) List

1. Security
- OAuth 2.0 authentication for all APIs
- Parent ownership validation for youth accounts
- Role-based access control (RBAC) enforced at gateway and service layers
- Audit logging of all fund transfers, spending limit changes, and dashboard accesses
- Data encryption at rest and in transit (TLS 1.2+)
- Input validation and output filtering

2. Compliance
- GDPR: Data subject rights, consent, data minimization
- PCI-DSS: Secure fund transfer, cardholder data protection
- ISO 27001: Information security controls, risk management

3. Performance
- API response time < 500ms for 95% of requests under normal load
- Dashboard API returns within 500ms
- Fund transfer API completes within 1s

4. Scalability
- Horizontal scaling via Kubernetes/container clusters
- Supports >10,000 concurrent parent users

5. Availability
- 99.99% uptime SLA
- High-availability clusters for APIs, services, DB

6. Reliability
- Automatic failover for service nodes
- Retry logic for transient errors

7. Maintainability
- Modular microservice architecture
- Reusable OpenAPI schema definitions
- Automated CI/CD pipelines

8. Auditability
- All parent actions logged with timestamp, account, action type
- Transaction logs persisted for 7 years

9. Disaster Recovery
- Recovery Time Objective (RTO) < 4 hours
- Recovery Point Objective (RPO) < 1 hour
- Daily backups, tested restores

10. Backup
- Encrypted daily backups
- Backup retention for 1 year

11. Monitoring
- Real-time metrics collection (Prometheus/Grafana)
- Alerting for API errors, latency, service downtime

12. Logging
- Centralized log aggregation (ELK/Splunk)
- Log retention for 1 year

13. RBAC
- Role-based access enforced at API Gateway and service layers
- Parent can only access/manage their own youth accounts

Mapped to ADRs:
- SCIB-25: Security, performance, audit, RBAC
- SCIB-26: API response time, ownership validation
- SCIB-27: Compliance, audit logging, error handling
- SCIB-28: Input validation, maintainability
- SCIB-29: Logging, monitoring, scalability
- SCIB-30: OpenAPI schema reuse, maintainability
