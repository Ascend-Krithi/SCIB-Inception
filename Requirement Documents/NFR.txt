Non-Functional Requirements (NFRs) List

Security
- OAuth 2.0 authentication
- RBAC enforced for parent/youth roles
- Input validation, output filtering
- Audit logging for all actions
- Data encryption at rest and in transit

Compliance
- GDPR: Data minimization, subject access, erasure
- PCI-DSS: Secure fund transfer, transaction logging
- ISO 27001: Information security controls

Performance
- API response time < 500ms (normal load)
- Fund transfer updates within 1s

Scalability
- Horizontal scaling via Azure App Service
- API supports >1000 concurrent users

Availability
- 99.99% uptime
- HA, automatic failover

Reliability
- Transaction logging
- Automatic failover for APIs

Maintainability
- Modular REST API
- Well-documented OpenAPI schemas
- Automated CI/CD pipeline

Auditability
- All user actions logged with timestamp and user ID
- Traceability matrix (acceptance criteria to design components)

Disaster Recovery
- RTO < 4 hours
- RPO < 1 hour

Backup
- Daily encrypted backups
- Automated restore testing

Monitoring
- Real-time metrics via Azure Monitor
- Alerting for failures, latency, errors

Logging
- Centralized log aggregation
- Structured logs for all APIs

RBAC
- Role-based access enforced for all endpoints
- Parent can only access/manage their youth accounts
