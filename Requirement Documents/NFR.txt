Non-Functional Requirements (NFRs) List

Security:
- OAuth2 authentication for all APIs
- RBAC for parent/youth access
- Audit logging of all actions
- Input validation and output filtering
- Data encryption at rest and in transit

Compliance:
- GDPR: Data subject rights, deletion, consent
- PCI-DSS: Secure payment processing
- ISO 27001: Information security controls

Performance:
- API response time <500ms (95% requests)
- Throughput: 1000+ concurrent users

Scalability:
- Horizontal scaling of API and DB
- Load balancing supported

Availability:
- 99.99% uptime
- Multi-zone deployment

Reliability:
- Transactional integrity for transfers
- Automatic failover

Maintainability:
- Modular codebase
- Automated CI/CD
- Clear API/ADR documentation

Auditability:
- All user actions logged
- Tamper-proof logs

Disaster Recovery:
- RTO <4 hours, RPO <1 hour
- DR tested quarterly

Backup:
- Daily encrypted backups
- Automated restore procedures

Monitoring:
- Real-time metrics (API, DB, auth)
- Alerting for failures, slowdowns

Logging:
- Centralized log aggregation (ELK/Splunk)
- Log rotation and retention policies

RBAC:
- Role-based access enforced at API level
- Parent can only access their youth accounts

Mapping to Design Decisions:
- Security, compliance, performance, scalability, and auditability referenced in ADRs SCIB-26 to SCIB-30 and enforced in API design and deployment.
