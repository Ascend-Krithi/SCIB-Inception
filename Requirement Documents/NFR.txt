Non-Functional Requirements (NFRs)

Security
- OAuth token validation for all APIs
- RBAC enforced (parent role only)
- Input validation and output filtering
- Audit logging for all fund allocations, limit changes, and dashboard accesses
- Data encryption at rest and in transit

Compliance
- GDPR: Data subject rights, consent, data minimization
- PCI-DSS: Secure handling of payment data
- ISO 27001: Information security controls

Performance
- Dashboard API response <500ms under normal load
- Fund transfer API response <700ms
- Transaction history API supports pagination for large datasets

Scalability
- APIs stateless, horizontally scalable
- DB supports partitioning and replication

Availability
- 99.99% uptime for API services
- Redundant infrastructure

Reliability
- Transactional integrity for fund transfers
- Automatic failover for critical services

Maintainability
- Modular API design
- OpenAPI/Swagger documentation
- Automated tests

Auditability
- All user actions logged with timestamp and user ID
- Tamper-proof logs

Disaster Recovery
- Daily encrypted backups
- RTO <4h, RPO <1h

Backup
- Daily backups for settings DB
- Encryption and offsite storage

Monitoring
- Real-time API metrics
- Alerting for errors and latency

Logging
- Centralized log aggregation
- Structured logs for audit

RBAC
- Role-based access control enforced for all APIs

Traceability
- All requirements mapped to ADRs and API endpoints
