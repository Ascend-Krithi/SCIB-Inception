Non-Functional Requirements (NFRs)

Security:
- OAuth token validation for all endpoints
- Parent ownership validation
- RBAC enforced (parent manages youth account)
- Data encryption at rest and in transit
- Audit logging for fund transfers and spending limit changes

Compliance:
- GDPR: Data protection, user consent, right to erasure
- PCI-DSS: Secure handling of fund transfers
- ISO 27001: Security controls and audit trails

Performance:
- API response time < 500ms under normal load
- UI loads dashboard within 1 second

Scalability:
- Horizontal scaling supported for APIs
- DB partitioning for large datasets

Availability:
- 99.99% uptime (HA deployment, failover)

Reliability:
- Automatic failover for API and DB

Maintainability:
- Modular architecture, reusable schema definitions
- Clear API documentation (OpenAPI)

Auditability:
- All user actions logged and searchable

Disaster Recovery:
- RTO < 4 hours, RPO < 1 hour

Backup:
- Daily encrypted backups of settings and transactions

Monitoring:
- Real-time metrics, alerting for API and DB

Logging:
- Centralized log aggregation and analysis

RBAC:
- Role-based access control enforced throughout

Input Validation:
- Fund transfer amount, spending limit, and account mapping validated

Output Filtering:
- Transaction history and dashboard data filtered for parent visibility
