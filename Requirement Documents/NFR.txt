Non-Functional Requirements (NFRs)

Security
- OAuth 2.0 authentication for all APIs
- Parent ownership validation
- RBAC enforced at API and UI
- Audit logging for fund transfers, limit changes
- Data encryption at rest and in transit

Compliance
- GDPR: Data subject access, deletion, consent logging
- PCI-DSS: Secure fund transfer, card data never stored
- ISO 27001: Information security controls

Performance
- API response <500ms under normal load
- UI loads dashboard in <2s

Scalability
- Horizontal scaling supported for APIs and UI

Availability
- 99.99% uptime for APIs
- Automatic failover for services

Reliability
- ACID transaction support for fund transfers
- Retry logic for payment service

Maintainability
- Modular REST APIs
- Reusable schema definitions
- Clear, versioned documentation

Auditability
- All fund transfers, limit changes, and login events logged
- Audit logs accessible to compliance teams

Disaster Recovery
- RTO < 4 hours
- RPO < 1 hour
- Tested failover and backup restore

Backup
- Daily encrypted backups for settings and transaction data

Monitoring
- Real-time metrics for API and UI
- Alerting for failures, latency, unauthorized access

Logging
- Centralized log aggregation
- Structured logs for all key events

RBAC
- Role-based access enforced for all APIs
- Parent can manage only their youth accounts

Enterprise Overlays
- Input validation, output filtering, audit logging, RBAC applied for compliance
- All endpoints and UI components mapped to ADRs for traceability
