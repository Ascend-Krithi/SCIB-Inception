Non-Functional Requirements (NFRs)

Security
- OAuth2 authentication for all APIs
- RBAC enforced at API Gateway
- Input validation and output filtering
- Audit logging for all sensitive actions
- Data encryption at rest and in transit

Compliance
- GDPR data processing and retention
- PCI-DSS for payment transactions
- ISO 27001 information security

Performance
- API response time < 500 ms for 95% of requests
- Fund transfer processing < 1 second

Scalability
- Horizontal scaling for API and DB services

Availability
- 99.99% uptime SLA
- Automatic failover

Reliability
- Retry logic for transient failures
- Transactional integrity for fund transfers

Maintainability
- Modular service architecture
- OpenAPI/Swagger documentation
- Automated CI/CD pipeline

Auditability
- All user actions logged with timestamp and actor

Disaster Recovery
- RTO < 4 hours, RPO < 1 hour

Backup
- Daily encrypted backups
- Backup verification and restore tests

Monitoring
- Real-time metrics collection
- Automated alerting for anomalies

Logging
- Centralized log aggregation
- Error and access logs retained for 1 year

RBAC
- Role-based access enforced for all endpoints

Mapping to ADRs
- All NFRs traceable to ADRs SCIB-25 to SCIB-30
